Test_your_nc

简单而言就是进行一个远程连接，区分ssh与nc连接，注意题目给的文件、提示以及会使用Linux系统就行了。（因为一般来说很多题目需要写脚本，而并非简单的远程连接）

尽管这部分没有太多东西记录，但有些还是得知道的。

  1. **后门函数/程序：**通常是指在软件、程序中故意或有意留下的隐蔽入口或者秘密功能，允许未经授权的用户绕过正常的安全机制去访问、控制以及修改系统，因此我们可以利用它对一个程序进行攻击（得在合法条件下，否则怎么进局子都不知道）。这也是后续我们需要找到或者构造出的一个非常重要的东西。

  2. execve函数：执行程序函数

    该函数需要三个参数：filename（要执行的程序文件名或路劲）、argv（以NULL结尾的字符串数组，表示传递给新程序的命令行参数）、envp（表示新程序的环境变量）。

前置基础：

这部分主要简单介绍了pwn的一些东西，主要目的是带领新手对pwn有一个大概的了解，不至于太过迷茫。pwn作为ctf比赛中的重点也是难点，对计算机的底层要求非常高，因此让许多人望而却步，既然选择要学pwn，那么就一定要坚持下去，不要三天打鱼两天晒网，那样是没有任何效果的。

PWN5-12

这一部分主要讲的是汇编语言的一些简单知识。

简单的总结一下一些的汇编语言知识（具体的在另一篇文章）：

  1. 寄存器：CPU内部用来存放数据的小型存储区域，是CPU的内部构造，不同的CPU的寄存器是不一样的，因此具体问题具体分析。一般分为通用寄存器、控制寄存器以及段寄存器。

  2. 部分汇编指令：

    **move：**将数据从一个地方转移到另一个地方。

    **add：**将两个值相加。

    **sub：**从第一个值中减去第二个值，并将该值保存到前者。

    **jmp：**无条件跳转到制定的地址。

    **push：**推入堆栈。

    **pop：**弹出堆栈。

    **call：**调用子程序，并将返回地址压入堆栈。

    **ret：**从堆栈中弹出返回地址，并将控制权转移回调用点。

还有一点就是move edx,ebx是将ebx的值赋给edx，而move edx,[ebx]是将ebx指向的地址的值赋给edx，有无[]其表达的含义是不一样的。

ok，这一部分就先讲到这，因为这部分就是简单的介绍一下汇编语言，带新手感受下氛围，具体的知识还得自己多去了解。

PWN13-16

pwn13

这道题主要考查的是如何使用GCC。那么就在这里简单介绍一下GCC以及如何使用。

简答来说，GCC就是一个c/c++编译器，gcc是GCC中的C语言编译器，其基本语法为：gcc [option] [filename]。其中option表示参数，filename表示相关文件的名字。

下面简单介绍一下一些参数：

  1. -o：直接生成可执行文件。
  2. -E：仅执行预处理。（生成后缀为.i的预编译文件）
  3. -S：执行预编译过后停止。（生成后缀为.s的预编译文件）
  4. -c：编译程序但不进行链接成可执行文件。（生成后缀为.o的文件）
  5. -g：生成调试信息，方便gdb。
  6. -v：查看版本，显示gcc执行的详细过程。

gcc的工作过程可以分为预处理、编译、汇编、链接四个步骤。

接下来就来简单的使用下gcc，用它编写一个简单的程序——hello world（在Linux系统中使用，因此得熟练使用Linux系统才行，后面再写篇文章来介绍一下Linux系统）。

  1. touch hello.c


再输入该代码，其中vim表示的是进行文件编辑，本句代码含义就是对文件hello.c进行编辑。

  2. #include<stdio.h>
int main()
{
    printf("hello world!!!");
    return 0;
}

gcc hello.c

    对其进行处理，可以得到./a.out这个可执行文件，最后运行该文件就可以输出hello world!!!

这里只是简单的介绍与使用gcc，详细一点的知识就自己去摸索。
